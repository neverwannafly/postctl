## Goal

## Work

1. **Global keys** per the Key map. Remove the old single-letter globals (`E`, `H`, `R`, `Ctrl-E`, `Ctrl-R` reload) and the tree's `n r D m d`; add `j k h l gg G Ctrl-d Ctrl-u` to the tree and lists you own; `[` `]` section steps; `:` opens the palette, and the palette accepts the exact inputs `q`, `q!`, `w`, `wq` (`w` flushes pending saves; `wq` flushes then quits). Keep `1 2 3`, `Alt-1/2/3`, `Tab`/`Shift-Tab`, `/`, `?`, `q`, `Ctrl-P`, `Ctrl-B`, `Alt-Up/Down`.
2. **Escape ladder and Ctrl-C ladder** exactly as specified. A running send or OAuth flow must still cancel on `Esc` when nothing else consumes it (existing tests must keep passing).
3. **Leader and prefixes.** `Space` (when the focused component is not inserting text) starts a leader sequence; `g`, `[`, `]` are prefixes in panes. After 300 ms without a follow-up key, a which-key overlay lists the valid next keys with labels (two or three columns, fits 80x24, ASCII-safe, `Esc` cancels, unknown key cancels and says so in the status line). Leader keys map to `Action.ID`s; the shell first asks the focused pane's `Registry`, then the shell's. A key whose action is missing or disabled is hidden from which-key and does nothing. Required IDs (create or rename actions so they exist): `request.find` (Q), `palette.open`, `env.switch`, `env.edit`, `history.open`, `history.request` (H1/V3; hidden until present), `tree.new`, `tree.rename`, `tree.delete`, `tree.duplicate`, `tree.move`, `runner.open`, `request.curl`, `request.curl.reveal`, `request.editor`, `request.reveal`, `request.snippet`, `cookies.open`, `sidebar.toggle`, `workspace.reload`, `response.diff` and `response.jq` (V3; hidden until present), `request.send`, `app.quit`, `jump.back`, `jump.forward`, `help.keys`. Every `Action.Keys` string shows the new key so the palette lists it.
4. **Section messages.** Add `FocusSectionMsg{Section string}` and `SectionStepMsg{Delta int}` to `pane.go` (doc comments). `g` + letter sends `FocusSectionMsg` after focusing the owning slot; the request, WebSocket and response panes handle it (request: `url params auth headers body pre tests settings`; WebSocket: `messages params headers auth settings`, plus `url`; response: `resp-body`, and `resp-history` ignored until V3). Replace the panes' Tab/arrow tab switching with `[`/`]` where it collided; Tab cycles panes.
5. **Pane movement.** `Ctrl-h/j/k/l` move to the neighbour in the current layout (three-pane, two-pane stacked, single-pane), computed from layout geometry recorded in `Update`/`SetSize`. When there is no neighbour, call `Options.OnEdge(dir) tea.Cmd` (new, nil = do nothing); T fills it in later with tmux handoff. Treat `Backspace` as `Ctrl-h` only when the focused component is not a text field in insert mode.
6. **Jump list.** Every time a request is opened (tree Enter, palette, switcher, history "open"), push it; `Ctrl-o` / `Space [` go back, `Ctrl-i` / `Space ]` go forward (`Ctrl-i` arrives as `Tab` in legacy encoding; with enhanced keyboard reporting it is distinct: only then bind it). Depth 100, deduplicate consecutive entries, drop deleted requests.
7. **Request pane keys that move to the leader:** `e`/`Ctrl-O` (`request.editor`), `y`/`Y` (`request.curl`, `request.curl.reveal`), `Ctrl-R` reveal (`request.reveal`), `Ctrl-G`/`s` snippets (`request.snippet`), `Ctrl-Z`/`Ctrl-Y` → `u`/`Ctrl-r` outside text fields. Keep `Ctrl-S`, `Ctrl-Enter`, Enter-in-URL-bar sending (D5, pitfall 13).
8. **Mode indicator.** Optional interface `ModeReporter { VimMode() string }` in `pane.go`. The footer starts with the mode label when a text field is focused (until V2 lands, existing widgets report `INSERT` while editing). Pending leader or prefix keys show in the footer too (`Space…`, `g…`).
9. **Badges.** Pane titles show `[1]`, `[2]`, `[3]` (ASCII-safe; hidden in the accessible look if the title would truncate the env badge).
10. **Docs.** `KeyCatalog` + `task keys`; fix the `docs/keys.md` header text (it cites the old Q11); help overlay content; README key section; drop the undocumented response `h j k l` mismatch by documenting what remains.
